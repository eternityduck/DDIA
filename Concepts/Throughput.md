# Throughput

**Definition:** The number of records or requests processed per second, usually the key metric for batch processing systems.

**Why it matters:** For batch systems, throughput rather than response time is usually the metric that matters.

**Example:** A batch job reporting '2M records/sec' is describing throughput; nobody cares how long any single record took.
